# Design Principles / 设计原则

## Calm by default / 默认克制
Use quiet surfaces and restrained accents. Avoid decorative gradients in routine admin workflows.

## Content first / 内容优先
Prioritize tasks, filters, and scan-friendly data. Only add KPI cards when they help decisions.

## Progressive disclosure / 渐进呈现
Expose frequent actions; place secondary actions in context menus.

## Consistent but flexible / 一致而灵活
AI conversations, workflows, tables, and settings share tokens, not necessarily identical layouts.

## Delight with purpose / 有意义的愉悦
Celebrate real wins, such as AI quota restoration. Keep animations short, nonblocking, and respectful of reduced-motion settings.

## Accessibility / 无障碍
Target WCAG 2.2 AA. Verify actual contrast, keyboard access, focus visibility, and non-color status cues.
